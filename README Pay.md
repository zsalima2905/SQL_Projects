# Payroll SQL Analysis

A beginner-level SQL project using **MySQL** to create and analyze a payroll database containing employee and department information.

# Project Overview

This project demonstrates SQL skills including database creation, table creation, data insertion, filtering, joins, aggregate functions, string functions, date functions, and salary analysis.

# Database Structure

## Departments

* Dept_Id
* Dept_Name

### Employees

* Dept_Id
* Emp_Id
* Emp_Name
* Gender
* Age
* Salary
* Commission
* Doj
* Manager_Name

# SQL Concepts Used

* Database and table creation
* `INSERT` and `SELECT`
* `WHERE` and `LIKE`
* `IS NULL`
* `JOIN`
* `GROUP BY`
* `HAVING`
* `COUNT()`
* `SUM()`
* `AVG()`
* `MAX()`
* `MIN()`
* String functions
* Date functions
* Salary calculations

# Analysis Performed

* Counted total employees
* Retrieved employee names in different formats
* Analyzed employee name length and characters
* Identified employees based on name patterns
* Joined employees with department information
* Identified employees without commission
* Calculated salary with bonus
* Calculated annual salary
* Found highest, lowest, and average salary by department
* Identified departments with more than three employees
* Identified employees who joined in the current year
* Calculated employee experience in months
* Identified departments with average salary above ₹60,000
* Calculated total salary by department
